# Security policy

Morrow stores highly personal content and service credentials. Please do not open a public issue containing a vulnerability, API key, database, backup, message content, or deployment detail.

Until a dedicated private reporting address is published, report security issues through a private GitHub security advisory on the repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Remove all real personal data and credentials from reproductions.

Only the latest revision on the default branch is supported with security fixes.
